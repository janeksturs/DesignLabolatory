# DAC-BOARD-MOCKUP
Repository for files associated with Design Laboratory.

1. Project Overview
The main goal of the project is to develop a computer application that allows users to control the output levels of a DAC board equipped with three Digital-to-Analog Converters (DACs).

The board is controlled by a microcontroller, which communicates with a computer through a UART serial interface. The computer application provides a user-friendly interface for configuring DAC output levels and sending control commands to the microcontroller.

The system is intended to enable convenient and remote operation of the DAC board through a computer-based control application.

2. Project Goals

Develop a computer application for controlling the DAC board.

Implement UART communication between the computer and the microcontroller.

The system is intended to enable convenient operation and remote control of the DAC board through a computer-based application.

Provide an intuitive interface for setting DAC output levels.

Ensure reliable communication between the application and the microcontroller.

Test the complete system and verify its functionality.
